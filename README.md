# e-f-p

Personal site of Eden Fox Phillips, builder.

Live at [e-f-p.com](https://www.e-f-p.com/).

## Stack

- [Next.js 16](https://nextjs.org/) (App Router, fully static output)
- React 19, TypeScript
- Tailwind CSS 4
- JetBrains Mono, self-hosted

## Running locally

```sh
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Other scripts:

```sh
npm run build        # production build
npm run lint         # eslint
npm run check:links  # verify all outbound links resolve
```
